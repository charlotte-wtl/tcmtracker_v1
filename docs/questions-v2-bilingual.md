# Daily TCM Log — Question Set v2 (Bilingual Draft)

Replaces the table-format Google Doc. Structure per question: **Question** — Answer options (可複選 = multi-select where noted) — *Detail* (if applicable).
Chinese copy is a draft — please review for native fluency before this locks in. English glosses are new where the source only had Chinese.

Section order below matches the intended app flow: sections open one at a time; hitting "Done" collapses the current one and opens the next (can be re-opened anytime to edit); a section can be marked Done while empty (= skipped).
